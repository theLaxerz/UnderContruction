API Quick Reference

Message Format (WebSocket)

{
  "type": "execute",
  "tabId": null,  // null = active tab
  "command": "select.one",
  "payload": {
    "args": ["#myElement"]
  }
}

Available Commands

  • select: one, all, byId, byClass, byTag, byName, byXPath, atPoint
  • create: element, text, comment, fragment, fromHTML
  • manipulate: append, prepend, insertBefore, insertAfter, remove, replace, clone, wrap
  • content: html, text, outer, value
  • attributes: get, set, remove, has, getAll, toggle
  • classes: add, remove, toggle, has, replace, getAll
  • style: get, set, remove, show, hide, toggle, injectCSS
  • events: on, off, trigger, click, focus, blur, mouse, keyboard
  • traverse: parent, parents, closest, children, siblings, next, prev
  • dimensions: rect, offset, scroll, scrollIntoView, width, height
  • form: getData, setData, submit, reset, validate
  • utils: waitFor, getPageInfo, getLinks, getImages, highlight
